# Evidence: A Shorter GPU Lane (R-1, R-2, release validation)

Measurements for plan [`2026-11-20-gpu-lane`](../plans/2026-11-20-gpu-lane.md). The plan's §2 holds the figures
that motivated it (the gates of record, the anatomy of a child, the profiles); they are not repeated here. This file
records the acceptance runs of §6, fixed before they were taken, on the implementation branch `gpu-lane-plan` and its
base `main` at `3ed2f768`. Raw data: `~/scratch/gpu-lane/` (`r2/` the weapon runs, `r1/` the gates, `release/` the
release runs); scratch may be cleaned, the tables here are the record. The host was shared throughout: another
agent's gates and tests took the gate lock between runs and the GPU lock during them.

## 2. R-1: the scheduler (D-1, D-2, D-4)

One tree (`d579c3de`, branch `gpu-lane-r1`: the implementation branch at `51cf8122` plus a comment-only change in
`crates/client/tests/support/gpu_run.rs`, never merged), four `cargo gate package` runs in the order A, B, B, A,
one at a time, each a normal gate holding the gate lock. A is the gate binary of `main` (`3ed2f768`), B that of the
branch. Each run had its own `--stamp-dir` and `--log-dir` under `~/scratch/gpu-lane/r1/<run>/`, its stamp directory
seeded from one snapshot of the default stamps (plan Amendment 1, item 6), so no run passed at once. Every run
selected the complete suite (223 targets, 28 GPU binaries, 159 GPU children).

| Run | Start (UTC), load 1/5/15 min | `T` s | `C` s | `η` | Valgrind phase ends s | First GPU start s | General lanes end s | `GPU2` jobs | Lock waits s (longest) | `anon` peak |
|---|---|---:|---:|---:|---:|---:|---:|---:|---:|---|
| A1 | 16:01, 26.1 / 47.2 / 64.7 | 3,035 | 2,072 | 0.683 | 393 | 395 | 1,666 | 0 | 130 (37.9) | 36.9 GiB |
| B1 | 16:55, 18.7 / 37.8 / 51.0 | 2,469 | 2,140 | 0.867 | 299 | 2 | 1,453 | 13 | 866 (52.6) | 37.1 GiB |
| B2 | 17:43, 112.1 / 105.4 / 100.2 | 2,504 | 2,201 | 0.879 | 410 | 2 | 1,568 | 14 | 811 (58.9) | 37.4 GiB |
| A2 | 18:26, 43.7 / 74.5 / 70.7 | 2,800 | 1,938 | 0.692 | 264 | 266 | 1,380 | 0 | 154 (32.1) | 37.1 GiB |

`T` is `lanes.tsv`'s last end minus its first start; `C` the summed `run_s` of the ledger's children that took the
GPU lock; B's gate printed the same `C` and `η` in its own occupancy line (D-4), for example B1's "the children held
the GPU 2139.7 s of a 2469.2 s test phase, eta = C / T = 0.87".

**Acceptance (plan §6.2), in both pairs (A1, B1) and (A2, B2):**

| Rule | (A1, B1) | (A2, B2) | Holds |
|---|---|---|---|
| `η_B ≥ η_A + 0.10` | 0.867 ≥ 0.783 | 0.879 ≥ 0.792 | yes |
| `T_B < T_A` | 2,469 < 3,035 | 2,504 < 2,800 | yes |
| B's GPU lane starts before the last valgrind job ends; no general job beside a valgrind job | first GPU start 2 s, valgrind ends 299 s; none | 2 s, 410 s; none | yes |
| Every target passes; no `FLAKY` or `TIMED OUT` in B that A lacks | all green, no such line in any run | same | yes |
| No `exit=lock-timeout` ledger line | one in every run, A's included: `busy lock probe` (`gpu_validation_tests`), the harness's self-test of a lock wait that must expire (wait 1.0 s, never a GPU child) | same | yes, read as the rule's intent (see below) |
| No child lock wait above 150 s | longest 52.6 s | 58.9 s | yes |
| `anon` peak below 56 GiB | 37.1 GiB | 37.4 GiB | yes |

The one `exit=lock-timeout` line of each run is the harness's own self-test of the lock timeout, run with a 1 s
wait against a held lock, in A as in B. The rule guards against GPU children starved by the second GPU job (D-2);
no child of a GPU test timed out waiting in any run. The rule is not changed; this reading is recorded for review.

**What moved.** The prediction was `η` about 0.62 → 0.80; with D-3 in both arms it was 0.68 → 0.87. The test phase
fell by 566 and 296 s (19 % and 11 %). The GPU lane is still the critical path: it ends 1,016 and 936 s after the
general lanes in B. The lock waits rose from about 140 s to about 840 s, the two GPU binaries' children queueing on
the fair lock (D-2), while the longest single wait stayed below 60 s.

The weapon target, as scheduled in the gates: 440 and 398 s in A1 and B1, 471 s in B2 (A's gates of record,
1,084 s before D-3).
