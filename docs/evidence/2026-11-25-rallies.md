### 1.2 Worlds (`world-wp0/`)

`scripts/wp.sh wp0 fe0447ab` exports the commit to `tree-wp0/`, builds `matchup_trace` and `route_trace` in release in
a separate target directory (`/home/spacescuffle/cargo-target/rallies-measure`) and runs `scripts/measure.sh` (the
hidden-harvesters script: the matrix with every battle on its seeds of record and 16 seeds, battle 31 on 100 seeds,
battle 33 on 64, the showcase and showcase effects scenarios on their default seed and seeds 1 to 8 for 6,000 ticks):
483 files, the reference for every later comparison by `scripts/compare.sh` (every output file byte for byte; logs
after removing the output path).

### 1.3 P-0: no measured world rallies or produces

`scripts/probe.sh fe0447ab` patches an archive of the commit (`scripts/patch_probe.py`, never committed) so that
`step_into` prints one line when a world starts, `admit_set_rally` one line per `SetRally` it is given, and the spawn
commit of `complete_production` one line per unit produced, with the producer's slug and whether it holds a rally.
It builds the trace binaries from that tree and runs `measure.sh` into `world-probe/`:

| Lines | Count |
|---|---:|
| `P0PROBE start` (worlds played) | 1,410 |
| `P0PROBE setrally` | **0** |
| `P0PROBE produced` (any producer) | **0** |
| produced at a Hatchery analogue | **0** |
| produced with a rally | **0** |

The probe's output files are byte-identical to `world-wp0` (483 files; the 21 differing logs differ only by the
probe's own lines, checked by removing them). So no measured world issues a rally or produces a unit, and plan §7's
predictions stand.

### 1.4 The skirmish match (`client-wp0/`, `client-probe/`)

`scripts/skirmish.sh` runs `skirmish_match_tests::a_match_is_won_through_real_input_alone` in release from an exported
tree in its own target directory (`rallies-client`). On WP0's tree the match is won at tick 6,342 (1,645 frames), the
pilot's stages at ticks 0, 0, 0, 22, 550, 586, 642, 4,502, 4,526, 4,822, 4,834, 5,086, 5,098, 5,350, 5,362 and
6,334. With the probe's tree the stage log is identical (only the wall time differs), and the probe prints 2 world
starts, 7 `produced by` lines, all at the Barracks analogue (`assembly_bay_dome`) with `rally=false`, and no
`setrally` line. So the skirmish issues no rally and produces nothing at a Hatchery analogue or with a rally.

Note on target directories: cargo hashes workspace members by their path relative to the workspace root, so two
exported trees built into one target directory share artifact names and are told apart only by modification
times. Every scratch script therefore touches the tree it builds (`find crates assets -type f -exec touch {} +`), and
the golden proofs use a fresh target directory per copy.
