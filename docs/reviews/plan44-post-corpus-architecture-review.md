## Support-cut numerical model: proposed reference investigation

The existing implementation defines an original piecewise-linear arc from widened actual f32 source points, subtracts support in f64, interpolates one ideal boundary in f64 and recomputes its geometric arc. Those are distinct rounded operations. The preserved test correctly rejects a positive reconstructed excess instead of quietly moving the reference. A solution must state which mathematical object defines the support, how its numerical enclosure is computed and how actual rounded controls are compared to it.

Propose a bounded offline experiment on the retained first Representation frame plus the existing exact-vertex, duplicate-edge, adjacent-representable, large-coordinate and tiny-radius unit cases. Keep original source bits, exact original edge indices, packet clock/path, chosen support and all output controls immutable as input evidence. Independently evaluate the same piecewise-linear cut at increasing precision, retaining interval/error bounds where available. Separate:

- cancellation in `total_arc - support` and loss of positive progress;
- interpolation rounding of the cut position/birth/path;
- recomputed segment-length and sum rounding;
- final f32 control-position/relative-age/path error against the unchanged reference.

Do not call increased-precision agreement a certified interval proof. An interval crossing the declared support boundary is unresolved; it is not permission to accept by rounding downward. Candidate representation strategies may preserve the cut parametrically on its actual source edge with an explicit reference-arc measure, or use a locally anchored coordinate representation with independently bounded reconstruction. Neither is approved here: both must show exact units, representability, effect on endpoint metrics, actual packed controls and the original8r support/culling contract. Changing the meaning of support from reconstructed geometry to a parametric measure requires an explicit blueprint amendment and review. Recording excess separately without checking it is not a fix.

Success for this investigation is a precise proposal that preserves the ideal reference and makes the retained ordinary case representable without changing the support/tolerances, while still refusing genuinely unrepresentable extremes. It must not conceal discarded positive support or alter incoming/exact-vertex/outgoing duplicate-edge provenance. Until that proof exists, retain the typed refusal and keep the reducer out of runtime.

## Capacity: what can be investigated without weakening the policy

The already completed original-vertex DAG is the exact baseline oracle for that representation. Preserve it as an independent regression. No additional run of a different greedy heuristic can overturn its19-control result.

An off-source polyline could theoretically use the same17-control capacity differently. Before implementation, its proposal must specify chronological interval ownership, whether parameterization remains original source arc, explicit endpoint constraints, age/path monotonicity, zero-arc temporal obligations and final rounded f32 error checks. A numerical optimizer finding a low residual is a candidate, not a guarantee: every original source vertex and required interval boundary must satisfy the exact declared metric after rounding. Any continuous-between-vertices guarantee must be derived for the actual parameterization; neither positional nearest distance nor a different curve parameter may silently replace the current metric. Failure to find a candidate is not an impossibility proof for arbitrary controls.

A curved primitive would change both geometric reconstruction and the eventual density evaluator. Counting only its endpoint records while storing extra tangents, knots or hidden source samples would misstate the bounded representation. Such a proposal must account for every scalar, maximum support, field integration and all additional per-fragment work. It is not currently authorized by the16 straight-segment limit. Likewise, retaining the full source history per fragment changes the work bound rather than solving this admission.

Changing the emitter's direction-dependent emission offset, suppressing legal turn samples, smoothing the trajectory or merging semantic discontinuities changes the reference producer. Those may be separately reviewable art decisions, but are not reducer corrections and cannot be evaluated by silently regenerating the reference. Keep this corpus's exact source and successful ordinary control traces available for any explicit future comparison.

The immediate deliverable should therefore be a falsifiable feasibility proposal or a documented rejection under the current representation, not a runtime fallback. No budget increase or relaxed tolerance is proposed in this document.
